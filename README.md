# Virtual-Keyboard
A Quickshell widget written with QML to add an onscreen keyboard widget with a drown down icon for Wayland systems.
[PREREQUISITES]

-Ydotool
-qtbased tools

[HOW TO USE]

Just run the "VirtualKeyboard.sh" and it'll show up as a widget on that monitor. Add this same file hyprland exec's if you wish for it to auto-start.
